표시 기준과 버스 노선 안내
  • 사람인 공고는 하늘색, 널스잡 공고는 살구색 태그와 왼쪽 띠로 구분합니다. 카드를 누르면 해당 사이트의 공고가 열립니다.
  • 1순위(노란 표)는 신장실·인공신장실 공고로 항상 맨 위에 놓이며, 그 안에서도 수간호사 공고가 먼저입니다. 2순위(회색 표)는 간호부장·간호과장 공고, 3순위는 나머지 간호부·간호사 공고이며 병동 공고가 그 안에서 먼저입니다.
  • 기본 화면은 부산 · 통근 1순위(장산성당 정류장 115-1·155·189-1·36 버스 한 번)이며, 통근 탭으로 2순위(반여3동 정류장 환승 115·144·44·52·해운대구1) → 도보가 먼 곳 → 확인 필요 → 갈 수 없는 곳을 따로 봅니다. 경남은 참고용이라 통근 판정 없이 1·2·3순위 순서로만 보여줍니다.
  • NEW는 최근 24시간 안에 처음 나타난 공고입니다. 15분마다 자동으로 다시 검색합니다.
  • 115-1 반송 → 반여 → 재송 → 벡스코 → 동백역 → 해운대 → 중동 → 좌동(해운대백병원) → 장산역 → 해운대구청
  • 155 서동(금정) → 명장·안락(동래) → 반여 → 재송 → 센텀 → 수영·광안 → 남천 → 경성대·부경대 → 대연 → 용당
  • 189-1 반송 → 반여 → 재송 → 원동 → 토곡·연산8동 → 연산교차로
  • 36 기장읍·일광·철마 → 반송 → 반여 → 원동 → 안락(동래봉생병원) → 연산교차로 → 연산역 → 거제역
  • 통근 2순위(반여3동 정류장 09183/09182 경유) — 115 센텀·수영강변·토곡, 144 동래역·온천장·부산대, 44 미남·사직·시민공원·초읍·당감, 52 교대·서면·범일·초량, 해운대구1(마을) 반여·재송
  • 「갈 수 있음」은 하차 후 도보 10분 이내, 「도보가 좀 멀음」은 10~20분, 「갈 수 없음」은 4개 노선이 닿지 않는 곳입니다. 기관 위치는 확인된 판정표 또는 카카오 지도로 자동 판정하며, 「위치 확인 필요」는 지도에서도 찾지 못한 경우입니다.
